# MITgcm → JAX (ECCO v4r4, LLC90)

Port of MITgcm **checkpoint66g** in the ECCO v4r4 configuration to JAX: differentiable (JAX adjoint, `ecco` and
`exact` modes) and parallel (tile sharding with tested gradients). Plan: `docs/plans/20260923-mitgcm-jax-port.md`.
Decisions: `docs/brainstorm-20260923.md`. Background and prior-port lessons: `CATALOG.md`,
`/work/ab0995/a270088/MIT/notes/*.md`. Read the plan's current task before touching code.

## Porting rules
- **Literal translation.** Only mechanical changes; any difference from the Fortran is a bug. No simplifications or
  "improvements" — a deviation needs Nikolay's approval and a `# DEVIATION:` banner in the code.
- **Every constant cites Fortran `file:line` + literal value.** Sources: `~/MIT/MITgcm_c66g` and the V4r4 override trees
  `~/MIT/ECCO-v4-Configurations/ECCOv4 Release 4/{code,flux-forced/code}` (overrides win over c66g).
- **Values come from the run's `data*` namelists and the build's `*_OPTIONS.h`, never from code defaults.**
- Port only branches V4r4 executes (`docs/BRANCHES.md` once Task 5 exists). Unsupported option ⇒ hard error.
- Oracle = instrumented gfortran c66g build (per-substep dumps). Gate first, then port; a new gate must fail on a
  planted error (negative control) before it is trusted. Fix a failing gate by fixing code or the experiment
  (teacher forcing / replay), never by loosening a tolerance.

## AD and parallel rules
- Masked, halo and padding lanes compute finite values (`ops/safe.py`); forward `where` does not stop a backward 0·inf.
- Never differentiate through solver iterations (cg2d in `custom_linear_solve`); fixed iteration counts; static config.
- Every backward-only switch (ecco mode) keeps the forward byte-identical and has an effect test on a live fixture.
- One code path for P=1 and P=N: arrays `[tile, k, j, i]`, halos filled from one exch2 map; exchanges via `ppermute`
  in `shard_map(check_vma=True)`. **`ragged_all_to_all` is banned** (wrong transpose). Global sums in fixed tile order.
- float64 everywhere (`mitgcm_jax/__init__.py` enables x64).

## Tests
- Every test file is listed with its cost group in `mitgcm_jax/tests/manifest.py` (unlisted ⇒ collection error).
- Tier 1 (< 10 min, < 100 tests, CPU compute node, every commit): `sbatch scripts/run_tier1.sbatch`; pass/fail from
  `scripts/check_pytest_report.py` + exit code, not from the job state. Smoke on login node:
  `JAX_PLATFORMS=cpu taskset -c 0-7 /work/ab0995/a270088/mambaforge/envs/mitgcm-jax/bin/python -m pytest -m smoke -q`.
- Tests decide, not confidence. Measure, do not guess. Check `sacct` before quoting a job ID.
